1. What is JSX, and why is it used?
 JSX is a way to write HTML-like code inside JavaScript. React uses it because it’s easier to create and read UI components.

2.What is the difference between State and Props?
 State is data that a component controls and can change, while props are read-only data passed from a parent to a child component.

3. What is the useState hook, and how does it work?
useState lets you add state to a functional component. You get a value and a function to update it. When the value changes, React re-renders the component.

4. How can you share state between components in React?
 To share state between components, keep it in a parent and pass it down as props. The child can read it or update it via a function from the parent.

5.. How is event handling done in React?
 React handles events using functions and camelCase props like onClick. You attach a function to handle actions like button clicks.
